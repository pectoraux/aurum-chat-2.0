# WORK-015 — Change Detection and Impact Analysis

## Objective

Detect material changes in the world and evaluate their potential company impact.

## Dependencies

WORK-014, WORK-012.

## Acceptance Criteria

1. Changes can be detected against prior world state.
2. Impact is represented as an inference, not fact.
3. Threshold crossing can create attention items.
4. Uncertainty is retained.
5. Investigation can be triggered when impact depends on unknowns.
