# WORK-007 — World Entities and Relationships

## Objective

Create the extensible entity/relationship world model.

## Dependencies

WORK-006.

## Scope

Implement canonical entity identity, extensible types, relationships, provenance links, and tenant ownership.

## Acceptance Criteria

1. Canonical entities can be created and resolved.
2. Relationships can be represented without hard-coded exhaustive ontology.
3. Relationships can carry provenance.
4. Cross-tenant references are impossible.
5. World-model writes are auditable.
