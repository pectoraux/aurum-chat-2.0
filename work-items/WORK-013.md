# WORK-013 — Company-Specific Learning Model

## Objective

Create versioned learned organizational preferences and usefulness signals.

## Dependencies

WORK-012.

## Acceptance Criteria

1. Explicit, behavioral, and outcome feedback are distinguishable.
2. Learned model versions are auditable.
3. Policy and learned preference are separate.
4. Learning cannot silently mutate explicit policy.
5. Learning updates have provenance and outcome references.
