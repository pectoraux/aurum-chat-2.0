# WORK-018 — Process Reconstruction

## Objective

Reconstruct recurring organizational workflows from observed events.

## Dependencies

WORK-005, WORK-016.

## Acceptance Criteria

1. Events can be grouped into process instances.
2. Recurring process patterns can be detected.
3. Manual effort and handoffs can be measured.
4. Process hypotheses remain distinguishable from observed events.
5. Automation opportunities can be represented for downstream evaluation.
