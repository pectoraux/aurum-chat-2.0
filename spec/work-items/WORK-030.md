# WORK-030 — MD Control Surface

## Objective

Create the management interface for company policy, attention, approvals, recommendations, workforce/agent oversight, and system explanations.

## Dependencies

WORK-022, WORK-027, WORK-028.

## Acceptance Criteria

1. MD can configure explicit policy.
2. MD can review recommendations.
3. MD can approve/reject controlled actions.
4. Evidence and uncertainty are visible for material recommendations.
5. Agent lifecycle can be reviewed.
6. Learned policy proposals can be accepted/rejected explicitly.
