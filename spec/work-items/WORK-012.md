# WORK-012 — Attention Policy

## Objective

Implement the explicit company attention model.

## Dependencies

WORK-004, WORK-011.

## Acceptance Criteria

1. Thresholds can be configured.
2. Attention evaluation is deterministic for a given state/policy.
3. Low-priority information can be retained without escalation.
4. Approval requirements are policy-controlled.
5. Learned behavior cannot override explicit policy.
