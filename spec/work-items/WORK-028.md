# WORK-028 — Conversation Domain

## Objective

Create the conversation model for Aurum as an organizational employee.

## Dependencies

WORK-012, WORK-013, WORK-027, WORK-033.

## Acceptance Criteria

1. Conversations are persisted and auditable.
2. Messages have actor/source/provenance.
3. Conversation can invoke cognition through the Cognitive Orchestrator without becoming authoritative truth.
4. Human feedback can feed the learning system.
5. Sensitive conversation access follows authorization.
6. Conversation responses distinguish evidence-backed facts from beliefs, hypotheses, and unknowns.
7. Conversation execution is traceable to the cognitive execution that produced it.
