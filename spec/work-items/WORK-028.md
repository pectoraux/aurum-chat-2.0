# WORK-028 — Conversation Domain

## Objective

Create the conversation model for Aurum as an organizational employee.

## Dependencies

WORK-012, WORK-013, WORK-027.

## Acceptance Criteria

1. Conversations are persisted and auditable.
2. Messages have actor/source/provenance.
3. Conversation can invoke cognition without becoming authoritative truth.
4. Human feedback can feed the learning system.
5. Sensitive conversation access follows authorization.
