# WORK-011 — Unknowns and Investigation Contracts

## Objective

Create first-class unknowns and investigation plans.

## Dependencies

WORK-010.

## Acceptance Criteria

1. Consequential unknowns can be persisted.
2. Unknowns carry importance and decision impact.
3. Candidate investigation paths can be represented.
4. Investigation cost/value can be represented.
5. Investigation execution is asynchronous and traceable.
