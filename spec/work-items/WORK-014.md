# WORK-014 — Environmental Intelligence Foundation

## Objective

Create external-source ingestion and company/environment relationship primitives.

## Dependencies

WORK-011, WORK-013.

## Acceptance Criteria

1. External observations enter the same evidence pipeline as internal observations.
2. External entities can be related to company entities.
3. Source provenance is retained.
4. External source reliability is represented.
5. Company impact analysis has a stable contract.
