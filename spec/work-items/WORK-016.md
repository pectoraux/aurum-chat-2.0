# WORK-016 — Organizational Knowledge and Transactive Memory

## Objective

Represent who knows, owns, influences, and has experience with organizational subjects.

## Dependencies

WORK-009, WORK-016 if reading this file: dependency is WORK-009 only; this correction is intentional.

## Scope

- expertise/capability signals;
- ownership;
- experience;
- decision authority;
- knowledge relationships.

## Acceptance Criteria

1. Aurum can identify candidate human sources for an investigation.
2. Knowledge relationships carry evidence.
3. Knowledge can decay/change over time.
4. No employee expertise claim is treated as absolute fact without evidence.
