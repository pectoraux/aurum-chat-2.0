# WORK-019 — Capability Graph

## Objective

Create the organizational capability graph.

## Dependencies

WORK-016, WORK-018.

## Acceptance Criteria

1. Required capabilities can be represented.
2. Employees, teams, agents, software, suppliers, and partners can provide capabilities.
3. Capability proficiency can be represented with evidence.
4. Capability gaps can be calculated.
5. Candidate gap-closing strategies can be compared.
