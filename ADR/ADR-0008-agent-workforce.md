# ADR-0008 — Agents as Organizational Workforce

## Status

Accepted

## Decision

Agents are persistent organizational actors with lifecycle, permissions, contracts, objectives, budgets, and performance.

## Rationale

Specialist agents are part of Aurum's action workforce, not merely transient tool invocations.

## Consequence

Agents can be recruited, evaluated, retained, modified, and terminated through explicit lifecycle state.
